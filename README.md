# HomeRun social assets (PUBLIC)

Everything in this repo is public. Only put finished images that are meant to be posted here.

## Rules
- One folder per post: `posts/YYYY-MM-DD_<network>-<slug>/`.
- Metricool drafts use the raw file URL: `https://raw.githubusercontent.com/homeruncare/social-assets/main/posts/<folder>/<file>`.
- When a new version replaces an asset, move the old version to the private repo `homeruncare/social-archive` (same folder path) and remove it here.
- Never put work in progress, brand source files, client or patient data, or anything internal here.
